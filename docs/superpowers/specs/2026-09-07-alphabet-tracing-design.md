# 알파벳 획순 따라쓰기 교육 웹앱 — 설계 (2026-09-07)

## 목적
모바일 브라우저에서 혼자 알파벳 획순을 익히는 교육 프로그램. 글자 윤곽선이 표시되고,
시범 애니메이션이 획순대로 내부를 채운 뒤, 학습자가 손가락으로 같은 획순을 따라 그린다.
시범과 다른 순서·방향·경로로 그리면 오답.

## 범위 (1차)
- 대문자 A, B, C, D, E, F (6자)
- 산세리프 정자체, Zaner-Bloser 계열 획순
- 학습 기록은 브라우저 localStorage (기기 단위). 서버 동기화는 2차.

## 구성 (정적 웹앱, 빌드 없음)
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css` | 세로 모드 모바일 레이아웃, 홈/연습 화면 |
| `letters.js` | 글자별 획 데이터 (100×100 좌표계, 획 = 점 목록) |
| `tracer.js` | 판정 엔진. 순수 함수. 화면 의존 없음 |
| `app.js` | 화면 전환, 캔버스 렌더링, 시범 애니메이션, 터치 처리 |
| `progress.js` | ProgressStore (localStorage). 나중에 서버로 교체 가능 |
| `tests/tracer.test.js` | 판정 엔진 자동 테스트 (node:test) |

## 획 데이터
- 각 글자: `{ strokes: [ [ [x,y], ... ], ... ] }`, 좌표 0~100, y는 아래 방향
- 획 굵기 W = 16 (좌표 단위). 곡선은 촘촘한 꺾은선.

## 판정 규칙 (획 하나 기준)
- 중심선을 일정 간격으로 재표본해 누적 길이 t(0~1)를 가진 점 목록으로 만든다.
- 허용 반경 R = W/2 + 6.
- 시작: 손가락 위치를 전체 중심선에 투영. 거리 > R 이거나 t > 0.15 → 오답 `start`.
  (획 순서를 어겨 다른 획을 그리면 시작점 검사에서 오답이 된다.)
- 이동: 현재 최대 진행도 maxT 기준 창 [maxT−0.10, maxT+0.30] 안에서만 가장 가까운 점을 찾는다.
  창 안에 R 이내 점이 없으면 오답 `off` (이탈, 역행, 건너뛰기 모두 여기서 걸린다). maxT 갱신.
- 손 뗌: maxT ≥ 0.85 → 정답. 미만 → 오답 `short`.
- 오답: 해당 획을 빨간색으로 0.5초 표시 후 지우고 같은 획 재시도. 3회 연속 오답 → 시범 자동 재생 후 같은 획부터.
- 정답: 획을 초록색으로 확정, 다음 획으로. 모든 획 완료 → 글자 완료.
- 이어 쓰기(joins): 글자 데이터에 `joins: [k]`가 있으면 k번 획을 85% 이상 그린 뒤 손을 떼지 않고
  k+1번 획 시작 구간에 들어오면 자동으로 다음 획 판정으로 넘어간다 (B의 굽은 획 두 개 = 2획 쓰기 허용).
  이어 넘어간 직후 진행도 20% 미만에서 떼거나 살짝 벗어나면 오답이 아니라 k+1번 획을 처음부터 다시 시작.
  시범은 여전히 3획으로 보여준다.

## 화면 흐름
1. 홈: A~F 버튼. 완료한 글자는 별 표시.
2. 연습: 큰 글자 윤곽, 획 진행 점(●○○), "시범 다시 보기" 버튼, 홈 버튼.
   - 진입 시 시범 자동 재생(파란색). 끝나면 채움을 지우고 "따라 써보세요".
   - 현재 획 시작점에 깜빡이는 점 표시.
   - 그리는 동안 중심선을 따라 초록색이 채워진다(손가락 진행도까지).
3. 글자 완료 → 축하 오버레이 → 다음 글자 또는 홈.

## 학습 기록
`localStorage["abc-trace-progress"]` = `{ "A": { completed, attempts, wrongs, lastAt }, ... }`
ProgressStore 인터페이스: `load()`, `recordAttempt(letter, wrongs)`, `markCompleted(letter)`.

## 테스트
- tracer: 올바른 궤적 → 정답. 역방향 시작 → `start`. 중간 이탈 → `off`. 역행 → `off`. 짧게 끝냄 → `short`. 2획을 먼저 시작 → `start`.
- letters: 모든 글자의 모든 획이 2점 이상, 좌표 0~100 안.
- 화면: 브라우저 미리보기(모바일 375×812)로 수동 확인.
