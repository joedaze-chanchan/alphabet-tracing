# 알파벳 획순 따라쓰기 교육 웹앱 — 설계 (2026-09-07)

## 목적
모바일 브라우저에서 혼자 알파벳 획순을 익히는 교육 프로그램. 글자 윤곽선이 표시되고,
시범 애니메이션이 획순대로 내부를 채운 뒤, 학습자가 손가락으로 같은 획순을 따라 그린다.
시범과 다른 순서·방향·경로로 그리면 오답.

## 범위
- 대문자 A~Z 26자 (2026-09-07 확장). 각 글자에 한글 읽기, 파닉스 소리, 예시 단어, 발음 mp3(audio/).
- 앱 대문은 3개 메뉴: 1 알파벳 따라쓰기(완성), 2 단어 따라쓰기(준비 중), 3 게임하기(완성, 아래 게임 절 참고).
- 산세리프 정자체, Zaner-Bloser 계열 획순
- 학습 기록은 브라우저 localStorage (기기 단위). 서버 동기화는 2차.

## 구성 (정적 웹앱, 빌드 없음)

## 획 데이터
- 각 글자: `{ strokes: [ [ [x,y], ... ], ... ] }`, 좌표 0~100, y는 아래 방향
- 획 굵기 W = 16 (좌표 단위). 곡선은 촘촘한 꺾은선.

## 판정 규칙 (획 하나 기준)
- 중심선을 일정 간격으로 재표본해 누적 길이 t(0~1)를 가진 점 목록으로 만든다.
- 허용 반경 R = W/2 + 6.
- 시작: 손가락 위치를 전체 중심선에 투영. 거리 > R 이거나 t > 0.15 → 오답 `start`.
  (획 순서를 어겨 다른 획을 그리면 시작점 검사에서 오답이 된다.)
- 이동: 현재 최대 진행도 maxT 기준 창 [maxT−0.10, maxT+0.30] 안에서만 가장 가까운 점을 찾는다.
  창 안에 R 이내 점이 없으면 오답 `off` (이탈, 역행, 건너뛰기 모두 여기서 걸린다). maxT 갱신.
- 손 뗌: maxT ≥ 0.85 → 정답. 미만 → 오답 `short`.
- 오답: 해당 획을 빨간색으로 0.5초 표시 후 지우고 같은 획 재시도. 3회 연속 오답 → 시범 자동 재생 후 같은 획부터.
- 정답: 획을 초록색으로 확정, 다음 획으로. 모든 획 완료 → 글자 완료.
- 이어 쓰기(joins): 글자 데이터에 `joins: [k]`가 있으면 k번 획을 85% 이상 그린 뒤 손을 떼지 않고
  k+1번 획 시작 구간에 들어오면 자동으로 다음 획 판정으로 넘어간다 (B의 굽은 획 두 개 = 2획 쓰기 허용).
  이어 넘어간 직후 진행도 20% 미만에서 떼거나 살짝 벗어나면 오답이 아니라 k+1번 획을 처음부터 다시 시작.
  시범은 여전히 3획으로 보여준다. 한 터치 안에서 여러 번 이어질 수 있다 (Z, W는 1획으로).
  이어 넘어간 직후 벗어났더라도 손가락이 다음 획 시작 구간으로 돌아오면 다시 이어 간다 (R의 굽은 획→다리).
- 대체 획순(alts): 글자 데이터에 `alts: [{strokes, joins}]`가 있으면 시범 획순과 대체 획순을 동시에 추적해
  어느 쪽으로든 맞게 쓰면 정답. 한 터치가 끝날 때마다 그 터치와 맞는 방식만 남긴다. 시범과 시작점 표시는 항상 기본 획순.
  (M: 위에서 내려 긋는 4획 기본 + 아래에서 올려 긋는 1~4획 대체)
- 사용자 지정 획순: T는 가로선 먼저. R은 굽은 획→다리 이어 쓰기(2획) 허용.

## 화면 흐름
0. 첫 실행: "한 글자를 몇 번씩 따라 쓸까요?" 설정(1~5, 기본 3). localStorage `abc-trace-settings`에 저장.
   홈 하단 "따라 쓰기 횟수: N번 · 변경"으로 나중에 바꿀 수 있다.
1. 대문(main): 메뉴 3개. 알파벳 메뉴에 완료 수(★ n/26) 표시.
1-1. 알파벳 고르기(home): A~Z 4열 버튼. 완료한 글자는 별 표시.
2. 연습: 큰 글자 윤곽, 획 진행 점(●○○)과 회차(1/3번째), "시범 다시 보기" 버튼, 홈 버튼.
   - 글자 이름 읽기(A 에이)와 🔊 버튼, 그 아래 파닉스 소리 [애] · apple 애플 (사과).
   - 글자를 열면 Web Speech API(en-US)로 "A. A. apple." 을 들려준다. 🔊로 다시 듣기.
   - 설정한 횟수만큼 반복. 한 회차를 다 쓰면 "잘했어요! n번째 써 볼까요" 후 획을 초기화하고 바로 다음 회차(시범 생략).
   - 진입 시 시범 자동 재생(파란색). 끝나면 채움을 지우고 "따라 써보세요".
   - 현재 획 시작점에 깜빡이는 점 표시.
   - 그리는 동안 중심선을 따라 초록색이 채워진다(손가락 진행도까지).
3. 글자 완료 → 축하 오버레이 → 다음 글자 또는 홈.

## 테스트

- letters: 모든 글자의 모든 획이 2점 이상, 좌표 0~100 안.
- 화면: 브라우저 미리보기(모바일 375×812)로 수동 확인.

## 게임하기 (2026-09-07 설계·구현)
- 화면: 위 60% 하늘 캔버스(비행선, 발사대, 레이저), 아래 40% 제어판(스펠링 + 쓰기 판 + 에너지 게이지). 상단 바에 점수·목숨·일시정지.
- 흐름: 난이도 선택 → 시작. 비행선(글자/단어 표시)이 위에서 내려온다. 터치로 목표 선택 → 쓰기 판에 첫 글자 윤곽.
  글자를 맞게 쓰면 에너지가 글자 수 분의 1씩 차고 다음 글자. 틀리면 그 획만 빨갛게 표시 후 재시도(그동안 비행선은 계속 내려옴).
  마지막 글자 완료 → 레이저(0.38초) → 폭발 → 점수(글자 수 × 10). 비행선이 땅에 닿으면 목숨 −1, 선택 중이던 목표면 쓰기 판 비움.
  목숨 3개 소진 → 종료 화면(점수, 격추 수, 최고 점수). 최고 점수는 난이도별 localStorage `abc-trace-game-best`.
- 난이도(words.js DIFFICULTY): 교육용이라 두 단계. 쉬움 = 글자 하나(50%)+3글자 단어, 속도 0.035 하늘높이/초, 한 대, 5초 간격.
  보통 = 3~4글자, 0.05, 두 대, 3.8초. 격추마다 4%씩 빨라지고 최대 2배. (어려움 단계는 2026-09-07 제거, WORDS.hard는 보존)
- 판정: 연습과 같은 LetterTracer. 쓰기 판은 pad.js(TracePad)로 분리.
- 파일: game.js(진행·그리기), pad.js(쓰기 판), words.js(단어 목록·난이도), progress.js BestScoreStore.

## 터치 입력 견고화 (2026-09-07)
- 좌표 보간: 직전 위치에서 지금 위치까지 2.5단위 간격으로 나눠 판정 (`LetterTracer.moveTo`). 빠른 손가락이 좌표를 드문드문 보내도 놓치지 않는다.
- 브라우저가 묶어 보낸 중간 좌표(getCoalescedEvents)도 모두 사용.
- 손 뗀 좌표를 `end(x, y)`로 넘겨 마지막 구간까지 판정한 뒤 끝낸다.
- 허용 반경을 화면 픽셀 기준 최소 40px로 보장 (`radiusMarginFor(padPx)`): 판이 작을수록 좌표 단위 여유를 키운다.
- pointercancel(시스템 제스처 등)은 오답이 아니라 현재 획만 조용히 되돌린다 (`LetterTracer.cancel`).
- 빨간 오답 표시 중에 새 획을 대면 기다리지 않고 바로 받는다.
- 게임 쓰기 판을 키우고(64vw/33dvh) 아래쪽 안전 여백을 두어 안드로이드 하단 제스처와 겹치지 않게 함.

## 닫힌 획(O, Q) 판정 (2026-09-07)
- 시작점과 끝점이 6단위 이내면 닫힌 획. 시작 판정은 모든 획에서 시작 구간(t ≤ 0.15) 안에서만 가장 가까운 점을 찾는다
  (닫힌 획에서 끝점 근처가 시작점으로 오인되던 문제 해결).
- 닫힌 획을 85% 이상 그린 뒤 시작점을 지나쳐 계속 돌면 진행도 1로 보고 정상 처리. 반대 방향(시계 방향)은 여전히 오답.

## 게임 방식 변경: 같은 단어 3연속 (2026-09-07)
- 비행선은 한 번에 한 대. 한 단어(또는 글자)가 세 번 연달아 내려온다.
  1. 뜻 고르기: 비행선에 영어(DUCK). 터치하면 4지선다(한글 뜻: 오리/…). 글자면 읽는 법(에이/…). 맞히면 에너지 가득 → 레이저.
  2. 따라 쓰기: 비행선에 영어(DUCK). 터치하면 쓰기 판에 스펠링 한 글자씩(기존 방식).
  3. 영어 고르기: 비행선에 한글(오리). 터치하면 4지선다(영어: DUCK/…). 글자면 한글 읽기(에이) → 글자 고르기.
- 오답 보기는 같은 난이도 단어 풀(글자는 A~Z)에서 뜻·영어가 겹치지 않게 3개. 틀린 보기는 빨갛게 비활성, 비행선은 계속 내려옴.
- 착륙하면 목숨 −1, 같은 단어·같은 단계가 다시 내려온다. 세 단계를 마치면 새 단어. 비행선 라벨 옆에 단계 번호(보라 1, 초록 2, 주황 3).
- 속도: 쉬움 0.028, 보통 0.031 (하늘 높이/초). 격추마다 2%씩, 최대 1.6배.
- 데이터: words.js MEANINGS(단어 뜻), PHASES, makeChoices.

## 참여자(프로필)와 이어하기 (2026-09-07)
- 첫 실행: 참여자 화면 "누가 할까요?" → 새 친구 만들기(캐릭터 이모지 16종 중 선택 + 이름 8글자) → 대문. 참여자별 첫 실행 때 따라 쓰기 횟수 설정.
- 대문 상단 칩(아바타·이름·바꾸기)으로 참여자 화면 이동. 참여자 카드에 완료 글자 수, ✕로 삭제(기록 포함).
- 저장: profiles.js ProfileStore(`abc-profiles`), scopedStorage(id)가 키를 `<키>@<id>`로 바꿔 기존 저장소(학습·설정·최고점수)를 참여자별로 분리.
  첫 참여자를 만들 때 참여자 없던 시절의 기록을 넘겨받는다.
- 이어하기(ResumeStore, `abc-trace-resume@<id>`):
  - 연습: 글자·회차·완료 획 수를 획 완료/회차 변경/뒤로 가기/탭 전환/페이지 숨김 때 저장. 알파벳 화면 배너 "A 쓰던 중이에요 (1번째 · 2획째부터)" → 시범 없이 그 획부터. 글자 완성 시 삭제.
  - 게임: 난이도·점수·격추·목숨·현재 단어와 단계를 격추/착륙/뒤로/그만/탭 전환 때 저장. 게임 메뉴 배너 "쉬움 · 30점 · ♥♥♥ · SUN 2단계 → 이어서 하기". 새로 시작하면 삭제, 게임 종료 시 삭제.
